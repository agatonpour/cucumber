# Card Game Tab

A web application for keeping track of games, scores, and results for a card game I regularly play with friends.

Built as a simple way to record our games and keep track of results over time.

## Features

- Record game results
- Keep track of scores
- View previous games
- Track results across players
- Responsive web interface

## Tech Stack

- TypeScript
- React
- Vite
- Tailwind CSS
- shadcn/ui

## Getting Started

### Prerequisites

Make sure you have Node.js and npm installed.

### Installation

Clone the repository and install the dependencies:
